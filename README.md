# NOTEBOOK

**QSOL-IMC experiments on NotebookLM / Gemini Notebook AI hosts.**

An experiment monorepo for studying source fidelity, critical evaluation, and unsupported elaboration in generated host discussions. Product names and settings are recorded as observed; model internals are not inferred from output.

**Start here:** [Getting Started](GETTING_STARTED.md) · [Instructions](INSTRUCTIONS.md) · [Experiment Index](experiments/README.md) · [Methods](docs/METHODS.md)

- [NPS-000 — The Semantic Vacuum Experiment](experiments/NPS-000/README.md): retained protocol and historical run record; publication separately reported at DOI [10.5281/zenodo.23222219](https://doi.org/10.5281/zenodo.23222219). The published bundle is not imported or independently audited here.
- [NPS-001 — Apollo 11 Comparative Audio Overviews](experiments/NPS-001/README.md): retrospective intake of three original audio attachments with verified byte counts and SHA-256 digests; condition mapping and substantive analysis pending.
- [Related archival work](docs/RELATED_WORK.md).

Each experiment keeps its protocol, inputs, run records, and analysis together. Large audio and publication artifacts can live in a versioned Zenodo record, with their URLs and SHA-256 digests recorded here.
