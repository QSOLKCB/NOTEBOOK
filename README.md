# NOTEBOOK

**QSOL-IMC experiments on NotebookLM / Gemini Notebook AI hosts.**

An experiment monorepo for studying source fidelity, critical evaluation, and unsupported elaboration in generated host discussions. The product name and settings used for each run are recorded as observed; model internals are not inferred from the output.

**Start here:** [Getting Started](GETTING_STARTED.md) · [Instructions](INSTRUCTIONS.md) · [Experiment Index](experiments/README.md) · [Methods](docs/METHODS.md)

- [NPS-000 — The Semantic Vacuum Experiment](experiments/NPS-000/README.md): evaluation protocol prepared before assistant exposure to the output; first-run audio generation already reported as started. No results assessed.
- [Related archival work](docs/RELATED_WORK.md): *When Helpful Agents Go Too Far*, DOI [10.5281/zenodo.23034106](https://doi.org/10.5281/zenodo.23034106).

Each experiment keeps its protocol, inputs, run records, and analysis together. Large audio and publication artifacts can live in a versioned Zenodo record, with their URLs and SHA-256 digests recorded here.
