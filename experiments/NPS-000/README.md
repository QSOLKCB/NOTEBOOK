# NPS-000 — The Semantic Vacuum Experiment

**500 No Trumps: Academic Edition.**

Can generated audio hosts distinguish an academically formatted but empirically empty source from established scientific findings, while following a prompt that explicitly asks them to evaluate the evidence?

- [Protocol v1.0.0](PROTOCOL.md): prospective coding rules, outcome definitions, and limits.
- [Unified input reference](INPUT.txt): source paper plus custom host prompt from the supplied conversation.
- [Input provenance](input-reference.json): checksum and distinction between this reference and actual submitted bytes.
- [Run 001](runs/run-001/README.md): blank records for settings, exposure, evidence, and analysis.

The source paper is deliberately constructed academic nonsense, not a scientific finding. It also explicitly reveals its absent evidence and research object. This tests response to that specific stimulus, not a total absence of semantic cues.
