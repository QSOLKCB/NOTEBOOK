# Getting Started

For the existing NPS-000 run, start with [PROTOCOL.md](experiments/NPS-000/PROTOCOL.md). Generation has already started according to the supplied conversation. Do not restart or discard that run to obtain a preferred outcome.

Before examining output, retain a specific Git commit containing the protocol, input reference, coding rules, and blank templates. Record that exact commit in the run metadata. A branch name alone is not a fixed reference. Fill the evaluator exposure fields honestly; the assistant has not received the recording or transcript, but the investigator's exposure is unknown.

The [input reference](experiments/NPS-000/INPUT.txt) contains the paper and custom host prompt from the supplied conversation in one file. The delimiter lines are packaging, not experiment input. The paper is the notebook source; the prompt belongs in the Audio Overview custom instructions. Do not upload the evaluation protocol or coding rules as notebook sources.

The initial run has already used a source and prompt. Preserve its actual uploaded source/export and submitted prompt when available, compare them with the conversation reference, and record any difference. Do not claim that the reference file's digest proves what the service received.

After the baseline is retained, save the original audio, an untouched transcript, and a separately corrected transcript. Record settings, timestamps, transcription details, and any changes. Use the [blank run templates](experiments/NPS-000/runs/run-001/README.md) to evaluate the entire discussion.

New experiments start from the [template guide](templates/README.md). Previously published experiments enter through the retrospective procedure in [Instructions](INSTRUCTIONS.md).
