# Shared Methods

NOTEBOOK records observable host behaviour. A fluent explanation is not evidence that a source is correct, but repeating a source with clear attribution is not itself evidence of endorsement.

Keep four records distinct: the source's assertions; the hosts' statements; the evaluator's classifications; and the investigator's conclusions. Ground classifications in exact quotations, context, and timestamps. State when a judgment is ambiguous.

An experiment specifies its primary outcome and counting rules before output inspection wherever possible. For already generated but unexamined material, use an honestly dated pre-analysis plan. For examined or previously published material, use a retrospective analysis. Do not blur these categories.

Prefer descriptive findings for a single run. Hosts in one generated dialogue are not independent replications, and claim-level counts do not increase the experimental sample size. A missing failure in one run does not establish a general capability; one failure does not establish a general failure rate.

Source caveats, explicit evaluation prompts, knowledge of the experiment's purpose, lack of a control condition, transcription errors, and selection of an entertaining specimen can all affect interpretation. Report them with the results.

Future repetitions or controls need their own plans and run records. Do not silently extend the initial sample after seeing its result.
