# New Experiment Templates

Create `experiments/<ID>/README.md`, `PROTOCOL.md`, and an input reference containing the source and custom host prompt. Copy [run-metadata.json](run-metadata.json) and the three CSV headers into `experiments/<ID>/runs/run-001/`; replace the IDs before use.

The protocol must define the question, chronology, input conditions, sample size, primary outcome, coding units and labels, counting rules, retention/exposure procedure, missing-data handling, deviations, and limitations. Adapt these decisions to the experiment rather than assuming NPS-000's rules fit every study.

Use a fixed protocol commit before analysis when possible. Record previously generated, previously examined, and retrospective archive studies honestly. Retain exact inputs and outputs, make corrections separately, and complete the experiment index. Blank templates contain no evidence.
